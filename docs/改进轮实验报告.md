# 场景检索流程与改进轮实验结果

2026-10-17；PostgreSQL 17.0 官方文档与核心源码。公开仓库：https://github.com/erha1499/agentic-rag-retrieval-ablation 。

## 结论与当前状态

**场景检索流程已经实现；本轮没有证据支持把RAG设为默认入口。** 明确符号、条件和已知术语的问题优先grep及区间读取；小文档可以全文读；大文档中需求局部且术语模糊时，RAG作为可选定位方法，再核验原文条件。具体代码判断仍回到grep和实际源码。

改进轮按预登记执行2开发题、6正式题，两组各跑一次：4个开发任务、12个正式任务全部实际执行并有终态。正式低、中、高各2题，文档、源码、联合各2题；4/6题涉及至少3000词文档页或3000行源码文件。新增Qwen公开价估算共**¥0.434183／¥3上限**，无未知用量、无在途预留、无HTTP失败。没有为花完预算或追分追加任务。

项目已迁移到用户指定agent目录下的独立仓库，Codex项目为 `retrieval-ablation`，本聊天已归入。首轮完整数据位于本地 `local_history/首轮/`，仍保持暂停；旧入口有兼容链接。首轮36题并未完成，本报告不将缩量结果冒充原36题结果。

## 流程如何工作

| 问题场景 | 默认动作 | 核验边界 |
|---|---|---|
| 校验逻辑、函数、条件、锁和调用顺序 | grep源码符号/错误文本，必要时区间读取 | 真实分支、返回值和先后关系，不能从函数名猜实现 |
| 少量文档或已定位的小页面 | grep定位路径与大小；需要全貌时全文读 | 已有足够证据即可结束，不强求多调一次工具 |
| 大文档、少量明确规则 | 优先grep精确术语；术语不确定时B可用RAG | RAG只是定位，重要条件和例外仍回原文 |
| 文档与源码联合问题 | 文档定位规则＋grep源码核验 | 两类证据需实际关联 |
| 全局综述、完整清单或所有分支 | 定位完整范围后分章节/连续区间读 | 不能把top-k局部命中当完整性证明 |
| 运行环境数据缺失 | 说明已查材料支持不了什么、还缺什么 | 不编造配置公式、精确最优值或全库否定 |

共同提示词实际来自 `prompts/检索流程.md`，流程图和说明在 `docs/检索流程.md`。两组共享该提示词、全文/区间读取上限12000字符、最多8次模型调用、单次输出1200 token、180秒时限和一次共享修正机会；串行AB/BA交错执行。A为grep＋读取，B额外有rag_search。B不调用RAG的任务也保留在B分母中。

引用位置检查只允许实际收到的行号。首次没有正文证据时允许一次反馈后补检索；已有证据但引用错误或截断时，只允许一次简洁修正。错误位置不能冒充complete；位置合规也不等于语义正确。源码、语料和原始日志均只读或保留原样。

## 哪些问题解决了，哪些仍存在

- 已实现大文件区间读取和返回限额，程序不会悄悄截断完整读取；预算不足立即停止后续调度。正式没有输出length截断，所有任务都取得过正文证据。
- N06两组引用范围校验失败，被保留为evidence_validation_failed；其非空回答仍逐事实评分，没有重跑或伪装成完成。
- 事实忠实度尚未完全解决。仍出现锁强度泛化、未核验的实现扩写、将名义等待预算说成实际时间保证等问题；高难联合题均未严格通过。当前流程适合辅助查证，还不能替代人工代码审阅。
- 提示词是建议的路由策略，不是强制分类器。N01两组最终都通过，但A只用grep，B在grep后使用RAG；N02术语明确，A只用一次grep即可取证，B进行了更多检索。不能从页面大小单独决定工具。
- 本批没有实际调用不带行范围的全文读取。成功的读取均为局部区间；小文档全文能力经过本地Mock验证，未宣称本轮已测出它的在线性能优势。摘要中的全文/范围次数是请求数，包含失败；`工具路由.json`另存成功read_mode计数，不混同两者。

## 评分与审裁透明度

三名隐藏组别代理各评4份答案，再由根代理抽核；不是独立人工评分。原始盲审严格通过2/12，根代理在查看组别映射前，对两份边界答案审裁为通过：

- E008正文先提供了正确路径与较宽行范围，并逐字引用支持两必要事实的原文；总结处行号错位作为精度问题保留，认可已有等效有效出处。
- E010精确API、集合来源和分支均正确；没有明示包含所有非唯一索引，不把题干未要求进一步展开的集合定义当作隐藏评分条件，保留中文术语精度备注。

另对E001零超时主要语义的覆盖做审裁，并将3处“事实未完整覆盖却标完整证据支持”的字段统一为false。原始评审、最终逐事实评分及审裁说明都公开保留；结果对小样本与审裁边界敏感。两种评分口径都不能证明B质量更好。
