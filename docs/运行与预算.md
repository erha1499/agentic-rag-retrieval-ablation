# 如何复现与控制新增费用

本页命令对应已完成的改进轮原题。新修订的[自然问法版](自然问法评测题.md)保存在 `data/自然问法版/`，尚未接入运行器，也没有重新执行；请勿把下面的默认命令当作运行新版题集。

本轮比较同一个Agent在相同检索流程下，增加RAG工具的增量影响。正式6题共12任务，低中高各2题；开发2题共4任务。模型沿用qwen-plus-2025-12-01（非思考，temperature=0），查询向量qwen3.7-text-embedding，精排qwen3.7-text-rerank。

新增最多3元覆盖开发、正式、查询向量、精排和失败重试。请求前按保守费用上界预留，按返回usage结算；未知用量保留上界，在途预留也占预算。预算或无有效上界立即停止后续调度，未启动题保留分母。公开价估算不等于核实扣费；3元是上限，无需花完。

## 本地检查

需要Python 3.12+、ripgrep，以及requirements.txt中的NumPy与BeautifulSoup。真实API调用只用标准urllib。

```sh
python3 test_qwen_client.py
python3 test_runner.py
python3 test_evidence.py
python3 test_evaluation.py
```

这些测试使用临时数据和假客户端，不调用模型。语料构建器可单独运行 `python3 build_corpus.py --self-test`。

## 语料和索引

已有语料与向量在本次本地迁移中完整保留：`local_history/首轮/` 保存首轮归档、调用记录与索引，当前data目录以项目内部相对链接复用。该目录及大体积缓存受gitignore保护，未发布。共享链接的语料和索引禁止原地重建，以保护首轮冻结证据。

公开仓库不包含向量文件，克隆后需另备匹配的语料、chunks.jsonl、索引配置、vectors.npy和keyword.sqlite，或者在独立目录从官方归档重建。**本轮3元是复用已有索引的新增调用预算，不包含首次从零建库费用。** 默认建库客户端同样限额3元，不保证能完成全库向量化；首次建库应另行规划并授权预算，不得混入本轮账本。

两个官方归档：

- https://ftp.postgresql.org/pub/source/v17.0/postgresql-17.0.tar.bz2
- https://ftp.postgresql.org/pub/source/v17.0/postgresql-17.0-docs.tar.gz

匹配哈希以冻结清单和语料manifest为准。源码授权见third_party/postgresql-COPYRIGHT。

## 真实调用

通过安全环境提供DASHSCOPE_API_KEY与DASHSCOPE_BASE_URL，不写入仓库或日志。先检查experiment_config.json预算为3，再串行执行：

```sh
python3 run_experiment.py dev --workers 1
python3 run_experiment.py test --workers 1
```

已有终态任务自动跳过；running残留必须先核进程与账本，不能直接删掉重跑。本轮失败保留，不因答案不好追加正式次数。

完成后生成隐藏组别评审包，评审者不读private_mapping：

```sh
python3 prepare_review.py --split test
# 按discuss/评分规则.md逐项评审并写review_*.json
python3 summarize.py --split test
```

本地原始模型轨迹与费用账本位于runs/，不提交到GitHub。公开脱敏汇总位于results/改进轮/，另写本地outputs/。每个重要结论仍需语义核验；引用位置验证不等于事实正确。

首轮与改进轮同时改变了提示词、读取方式与输出约束，不能将跨轮差额单独解释成RAG效果。每轮内部保持A/B共同条件，只增加B的rag_search。
