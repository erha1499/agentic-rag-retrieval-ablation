# 仓库公开范围与数据来源

本仓库跟踪当前代码、系统提示词、检索Skill、题集、方案、冻结哈希及脱敏结果。维护时直接覆盖源文件，历史版本由Git保留。真实密钥、环境文件、原始模型调用日志、原始归档、归一语料与大体积向量缓存不提交。原始轨迹和费用账本在本地保留，用于复核；历史改进轮已归档至local_history/改进轮/，当前运行使用runs/。

PostgreSQL 17.0 材料来自官方发行目录：https://ftp.postgresql.org/pub/source/v17.0/ 。源码归档经官方SHA256核对，文档包保存本地SHA256。原文与衍生文本遵守 `third_party/postgresql-COPYRIGHT`。

公开结果中的费用为供应方usage乘公开价，不等于已核对扣费。未知、失败、未执行和未完成分母保留。公开仓库本身不包含可直接复用的私有API凭据，也不会因运行离线测试而请求模型。
