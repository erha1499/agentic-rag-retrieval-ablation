# 隐藏组别评分规则

同一套 Agent 在相同系统提示词、模型、语料、读取能力、轮数和时限下执行，A 有 grep 与文件读取，B 额外有 rag_search。共同检索流程直接包含在系统提示中。题目、必要事实和证据在执行前冻结。评审不以命中次数、回答篇幅或工具选择是否符合预期直接判正确。

本轮主目标是回答质量不降低时的在线降本，质量与准确率作为约束，不要求提升。下列绝对评分尺度保持不变；成本目标不构成放宽事实、引用或错误标准的理由。

## 执行分母

- 计划题数来自实际冻结题集，不假设固定题数。每题计划 A、B 两个任务。
- 只有账本存在相应标签的真实 `api_call` 事件，才算已执行。未启动、预算阻断且没有 API 请求的任务保留在计划分母，不伪装成已执行失败。
- 已执行但没有最终答案，单列未完成，`assessable=false`、`fact_results=[]`、`strict_pass=false`。有截断回答则逐事实评分，任务完成状态另列。
- 只有 `run_status=complete` 且内容严格通过，才计为任务成功。配对比较只使用 A、B 都实际执行并完成评审的题；单边执行、在途和未评审另列。

## 每份答案的检查

1. 对每个必要事实记录 `covered`、`correct`、`evidence_supported` 和中文理由。允许表述不同但含义等价；少条件、错例外或只回答半个问题均须体现。
2. 必要事实应由 Agent 实际收到的原文支持，并用 `【相对路径:L起始行-L结束行】` 引用定位。运行器的格式和范围检查仅证明引用可定位，不能证明语义正确；必须核对引用是否支持对应结论。
3. `received_windows` 只表示实际返回的行号：范围读取按 start/end，grep 按返回行，RAG 按实际父块范围。文件的 `total_lines` 不意味着全文已读。仅列出文件名不构成已读证据。
4. 允许同等有效的替代出处，不要求逐字命中金标准片段。若引用边界略有偏差但 Agent 已读到完整语义上下文，评审注明，由根代理审裁；不得悄悄降低全部答案的引用要求。
5. 实质错误的额外断言也记入 `material_errors`，不能因主体正确而忽略。文档、源码、联合题的来源要求以题干为准；联合题应建立两类证据的联系。
6. `strict_pass` 要求全部必要事实齐全、正确、实际有支持，引用及题干来源要求满足，且没有重要额外错误。信息不足题允许合理澄清或带条件建议，不强求完全拒答或制造引用；必须单列，不将澄清校准归因为 RAG 检索收益。
7. 发现冻结金标准错误时报告 `gold_issue` 给根代理。不得自行改题或选取有利评分；根代理须保留原评分并用 `gold_issue_resolved` 和说明记录审裁。

## 评审隔离与输出

答案按固定随机种子打散成最多三份互不重叠的包。评审代理只能读取自己的 `packet_*.json`、本规则和本地冻结语料；不得读取 `private_mapping.json`、`runs/test` 或 `runs/dev` 中带组别的文件，不按回答风格推断组别。评审是隐藏组别代理评审加根代理抽核，不能称为独立人工评分。

每份评审输出 JSON 数组，每项字段为：`blind_id`、`assessable`、`fact_results`（每项 index 从 1 连续编号，covered/correct/evidence_supported 为布尔值，comment 为中文）、`material_errors` 数组、`source_requirement_met`、`citation_supported`、`strict_pass`、中文 `reason`、`evidence_paths_checked` 数组。无答案须三个布尔通过字段均为 false。有答案无论是否截断都必须为全部必要事实评分。

开发题与正式题评审分开存放，不把开发题并入正式正确率。预算停止时仍输出部分结果，未评审的严格通过率保持空值，不能当作零分或完整实验结论。

## 成本比较中的质量约束

隐藏组别评分完成后再恢复配对，逐题比较 B 相对于 A 是否观察到退化，不根据费用反改评分：

1. 同一个必要事实的“覆盖且正确”（`covered and correct`）和 `evidence_supported` 均不得由 A 的 true 变为 B 的 false，不能用另一项事实的改善抵消。删除 A 原本答错的内容，不单因 `covered` 从 true 变为 false 就判质量退化。
2. A 满足 `source_requirement_met` 或 `citation_supported` 时，B 也须满足。A 有可评分答案、完成运行时，B 不得变为无答案或未完成。
3. B 的 `material_errors` 数量增加时判退化；数量未增加但 B 仍有重要错误时，标记为需逐对审裁，核对错误内容、性质和严重程度。自由文本及错误计数相同不能自动说明错误相同、较轻或质量等效。
4. 任一侧未执行、在途、未评审或存在未审裁金标准问题时，质量比较保持未知。已确认的局部退化应保留，不能用其他未知项目覆盖。

上述字段检查只给出当前样本的保守观察门槛。双方严格通过数相同或均为零，不代表质量相同；双方未达到绝对全对，也不阻止报告成本差异与逐题质量约束结果。不得把自动门槛称为统计非劣或等效证明。

总在线费用比较保留全部任务及 B 未调用 RAG 的题，不挑选双通过题作为总体分母。只有全部计划任务双方均完成、有可评分答案且已评审，完整任务集合费用更低、费用无未知或在途、逐题已测质量维度未观察到退化，才可报告当前样本的受约束在线降本。仍有重要错误待审裁、部分结果和未知质量时不能直接判成功。建库、更新及摊销另报，在线降本不等于总投入回报已得到证明。
